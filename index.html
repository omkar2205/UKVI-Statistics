Data Guide

Applications are summed from Sponsored Applied. Outcomes are summed from Sponsored study, using only Issued/Granted and Refused decisions.

Grant Rate = Issued / (Issued + Refused). Refusal Rate = Refused / (Issued + Refused).

Important: applications and outcomes are period-level indicators, not matched applicant-level records. An application in one quarter may receive a decision in another quarter.

This GitHub version loads the Excel workbook from the repository instead of using Google Apps Script, so there is no SpreadsheetApp server call on every dashboard load.
