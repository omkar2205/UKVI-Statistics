Overall Study Visa

Uses Applied and Outcomes. This includes all study visa subtypes, main applicants and dependants.

Sponsored Study Only

Uses Sponsored Applied and Sponsored Outcomes. If the workbook still uses the older sheet name Sponsored study, the site reads that as Sponsored Outcomes.

Rates

Grant Rate = Issued / (Issued + Refused). Refusal Rate = Refused / (Issued + Refused).

Interpretation note

Applications and outcomes are period-level indicators, not matched applicant-level records. An application submitted in one quarter may receive a decision in another quarter.
